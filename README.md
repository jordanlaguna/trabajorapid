# 👷‍♂️ Bienvenido a RapidJobs

**RapidJobs** es una aplicación móvil desarrollada en **Flutter** con backend en **Firebase**, pensada para facilitar la búsqueda de empleo y contratación de servicios en **Costa Rica**. ¡Encuentra o publica ofertas de trabajo de forma rápida, sencilla y segura!

## 🚀 Características Técnicas

- ✅ **Flutter + Dart** para desarrollo multiplataforma.
- 🔥 **Firebase** para autenticación, base de datos y notificaciones.
- 🔐 **Login con Google** y gestión de sesión segura.
- 📱 Interfaz moderna, limpia y responsiva.
- 🧠 Notificaciones en tiempo real (FCM).
- 📍 Filtrado de servicios por ubicación y categoría.
- 🧑‍💼 Gestión completa del perfil de usuario.
- 📊 Sistema de valoraciones y experiencia por servicio.

---

## 🎯 Funcionalidades Clave

- 🔍 **Búsqueda y publicación de empleos y servicios.**
- 👤 **Perfil de usuario con control de información y preferencias.**
- 📨 **Mensajería en tiempo real entre usuarios.**
- 💾 **Favoritos y trabajos archivados.**
- 🛠️ **Amplia variedad de categorías (Mecánica, Asistente, Construcción, Transporte, etc).**
- 🔒 **Opciones de seguridad y privacidad desde la configuración.**

---

## 📅 Fecha de creación

El proyecto fue iniciado en **2024** con la visión de transformar la forma en que se conecta la oferta y demanda de trabajo en Costa Rica.
