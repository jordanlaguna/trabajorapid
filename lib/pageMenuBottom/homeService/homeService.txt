Importaciones: Importa los paquetes necesarios de Flutter y Firebase.

HomePageService: Es un StatefulWidget que representa la página principal 
de la aplicación.

_HomePageServiceState: Es la clase de estado para HomePageService. Contiene 
la lógica principal de la aplicación.

initState(): En este método, se inicializan los controladores de flujo y 
se llama a métodos para cargar datos de Firebase y calificaciones de usuario.

_loadUserRatingsFromFirebase(): Carga las calificaciones de usuario desde Firestore y 
calcula la calificación promedio para cada servicio.

_StarDataFromFirebase(): Carga los datos de calificación de estrellas desde Firestore.

_fetchDataFromFirebase(): Carga los datos de servicios desde Firestore.

buildCarousel(): Construye un carrusel de servicios utilizando el paquete carousel_slider. 
Cada servicio se muestra en un widget personalizado buildCuadro.

buildCuadro(): Construye un cuadro para un servicio individual que incluye título, contenido, 
calificación de estrellas y un enlace para ver más detalles.

buildCuadrosFromDatabase(): Construye una columna de cuadros de servicios utilizando los datos de la base de datos.

build(): Es el método que construye la interfaz de usuario de la página. 
Utiliza FutureBuilders para cargar los datos de servicios y luego construir los elementos visuales correspondientes.

main(): Método principal de la aplicación. Inicializa Firebase y ejecuta la aplicación Flutter.
